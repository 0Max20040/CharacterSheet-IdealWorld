# Distorted Multiverse - Ideal World

Лист персонажа для настольной ролевой системы "Distorted Multiverse - Ideal World".

## 🚀 Деплой на GitHub Pages

### Автоматический деплой (рекомендуется)

1. Перейдите в **Settings** → **Pages** вашего репозитория
2. В разделе **Build and deployment** → **Source** выберите **GitHub Actions**
3. Запушьте код в ветку `main` или `master`
4. Workflow автоматически соберёт и задеплоит сайт

### Ручной деплой

1. Соберите проект:
   ```bash
   npm install
   npm run build
   ```

2. Содержимое папки `dist/` задеплойте на GitHub Pages

## 📋 Функционал

- ✏️ Ввод имени и ранга персонажа
- 🧬 Мультиселект рас (с подкатегориями для Зверолюда)
- ✨ Мультиселект элементов (с подкатегорией Культура)
- 📊 Автоматический расчёт основных и побочных характеристик
- 🖼️ Загрузка изображения персонажа
- 💾 Сохранение/загрузка через localStorage
- 📁 Экспорт/импорт JSON файлов
- 📄 Экспорт в TXT
- 🖼️ Экспорт в PNG

## 🛠️ Локальная разработка

```bash
npm install
npm run dev
```

## 📦 Сборка

```bash
npm run build
```

Результат будет в папке `dist/`
